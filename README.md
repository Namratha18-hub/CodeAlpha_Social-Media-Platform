# 📱 Social Media Platform

A mini social media application where users can create posts, like, comment, and follow other users.

## 🚀 Features

- User Authentication
- User Profiles
- Create/Edit/Delete Posts
- Image Upload
- Like & Comment System
- Follow/Unfollow Users
- Responsive Feed
- Search Users

## 🛠️ Tech Stack

Frontend:
- React.js
- Tailwind CSS

Backend:
- Node.js
- Express.js

Database:
- MongoDB

Authentication:
- JWT
